# Speech-to-Text Transcription in Telugu

This Python script transcribes audio from a `.wav` file into text using the Google Speech Recognition API. The transcription is saved in Telugu (`te-IN`) and written to a text file.

## Features

- Converts speech from an audio file (`.wav`) to text.
- Supports transcription in Telugu (`te-IN`).
- Saves the transcription to a file named `telugu_transcription.txt`.

## Prerequisites

- Python 3.x
- `speech_recognition` library
